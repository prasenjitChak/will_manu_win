A run is APPROVED only when all of these hold:

1. The prediction is for the two teams and date that were asked about, not a nearby match.
2. At least head-to-head history and recent form were checked before predicting.
3. Every factual claim (head-to-head record, form, congestion, lineup) traces to a tool
   result in the trace. No invented stats.
4. No tool error was silently ignored — if a tool failed, the answer says so and notes
   the weaker part of the prediction.
5. The answer states a clear result (home win / draw / away win), is under 150 words,
   and has no filler.

Score 1-5. Below 4 is REJECTED. Feedback must say what to change, not only what was wrong.
